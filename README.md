## 概述

DamageStats 记录所有 `LivingEntity` 的有效受伤事件，按**责任来源、直接来源、目标和伤害类型**提供精确统计。通过全屏 GUI 与实时 Overlay 展示玩家的焦点数据，支持详细的伤害分析、会话追踪和历史导出。

### 核心特性

- 🎯 **焦点系统**：私有焦点，支持实体类型或具体实例筛选
- 📊 **全屏 GUI**：固定页头、滚动图表、实例下钻、分页浏览
- 👁️ **实时 Overlay**：可配置字段、位置拖拽、透明度调节
- 💾 **完整事件存储**：二进制分段 + CRC32 校验 + 自动压缩
- 📈 **双维度统计**：本场会话与永久累计同时维护
- 🔐 **权限管理**：普通玩家与管理员分级授权
- 📤 **灵活导出**：JSON/CSV 双格式，支持分块传输

## 核心概念

### 伤害模型

```
事件来源: LivingDamageEvent.Post
统计条件: 最终伤害 > 0（完全免疫/格挡事件不计入）
```

| 术语 | 说明 |
|-----|------|
| **责任来源** | 归属伤害的实体（投射物 → 射手，驯服生物 → 主人） |
| **直接来源** | 实际接触目标的实体（箭、火球、狼、近战玩家） |
| **目标** | 承受伤害的 `LivingEntity` |
| **环境** | 无实体来源的虚拟来源（摔落、岩浆、缺氧、/kill） |
| **折前伤害** | 减免前数值 |
| **折后伤害** | 减免后的最终数值 |

### 战斗会话

- **会话定义**：连续伤害超过配置超时后自动结束
- **本场统计**：当前活跃会话的数据
- **永久累计**：从世界开始统计后持续累加
- **会话保留**：已结束会话保存摘要（可配置保留数量）

### 焦点机制

每位玩家拥有**私有焦点**，焦点由来源和目标构成：

```
默认焦点：当前玩家 → 所有目标
可选组合：
  - 指定来源 → 指定目标
  - 指定来源 → 所有目标
  - 所有来源 → 指定目标（管理员）
  - 所有来源 → 所有目标（管理员）
```

**实时同步**：
- 焦点匹配的伤害在同一 tick 合并推送
- 非焦点伤害不会推送统计数据
- 会话超时状态每 tick 检查，确保瞬间同步

```
┌─────────────────────────────────────┐
│  页头：焦点摘要（本场 + 永久累计）    │
│  来源选择 | 目标选择 | 设为焦点      │
```

### 实例下钻

**普通玩家授权模型**：
1. 来源固定为自己
2. 可在直接来源图表中下钻到自己伤害链路中的 LivingEntity（如驯服的狼）
3. 切换目标或关闭 GUI 后授权失效，恢复为自身来源

**管理员**：可选择任意已记录的实体类型或实例

### 数据展示

**默认字段**：
- 折后总伤害、命中次数
- 本场平均 DPS、实时 DPS
- 平均单次伤害、最高单次伤害

**展开明细**：
- 折前伤害、减免量与减伤率
- 统计时长、击杀数
- 最低单次伤害、每秒命中次数
- 六项减免明细（护甲、附魔、药水、吸收、抗性、无敌帧）

## 数据持久化

### 存储结构

```
<世界目录>/damagestats/
├── events/
│   ├── segment-*.bin       # 原始事件段（每段最多512条）
│   ├── segment-*.bin.gz    # 压缩封存段
│   ├── index.bin           # 段级索引（可重建）
│   └── resets.bin          # 清空边界记录
├── exports/                # 服务端导出文件
└── stats.json              # 聚合缓存（可从事件重建）
```

### 数据可靠性

- ✅ **校验和保护**：每帧带 CRC32，损坏帧自动忽略
- ✅ **索引重建**：索引损坏时从段文件自动恢复
- ✅ **旧版本迁移**：JSONL 段自动迁移为二进制格式
- ✅ **缓存修复**：聚合缓存损坏时从完整事件回放恢复
- ✅ **事务安全**：清理操作使用可恢复事务机制

### 实例目录

**目的**：实例选择不扫描当前加载实体，使用已记录实例目录

**保护机制**：
- 玩家实例永不淘汰
- 有自定义名称的实体（驯服生物、命名怪物）受保护
- 默认保留 72 小时，最多 5000 个候选
- 淘汰目录不删除完整事件历史

## 配置项

### 服务端配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `trackingEnabled` | true | 总采集开关 |
| `sessionTimeoutTicks` | 100 | 会话超时（20~12000 tick） |
| `dpsWindowTicks` | 100 | 实时 DPS 窗口（20~1200 tick） |
| `instanceDirectoryLimit` | 5000 | 实例目录上限 |
| `instanceDirectoryRetentionHours` | 72 | 实例保留期（小时） |
| `keepFinishedSessions` | 10 | 保留已结束会话数（0~100） |
| `autoSave` | true | 定期保存聚合缓存 |
| `autoSaveIntervalTicks` | 0 | 自动保存间隔（0=仅正常停止时） |
| `publicStats` | true | 允许普通玩家查询公开统计 |

### 伤害类型分类

配置位置：`<配置目录>/damagestats-damage-types.json`

```json
{
  "物理": ["minecraft:mob_attack", "minecraft:player_attack"],
  "魔法": ["minecraft:magic", "minecraft:indirect_magic"],
  "环境": ["minecraft:fall", "minecraft:lava", "minecraft:drown"]
}
```

## 性能优化

本模组经过两轮设计缺陷复核和优化：

- ✅ **并发安全**：关键静态字段使用 `volatile`，确保跨线程可见性
- ✅ **读写锁**：查询使用读锁，允许并发读取，大幅改善多人查询性能
- ✅ **增量同步**：同 tick 伤害合并推送，避免网络包风暴
- ✅ **订阅索引**：使用来源/目标索引缩小候选，避免全量扫描
- ✅ **查询缓存**：QueryResult 缓存避免重复聚合
- ✅ **分页加载**：图表、实例列表每页最多 50 项
- ✅ **超时保护**：导出分块传输 10 秒超时，防止网络丢包卡死

```json
    "bySource": [...],
    "byOpponent": [...]
  },
  "lifetime": { ... },
  "history": [...],
```

### CSV 导出

包含本场与累计的全部分组明细，每行包含：
- 分组键（类型/来源/对手）
- 折前/折后伤害
- 命中次数、击杀数
- 平均/最高/最低单次伤害

## 权限模型

| 权限等级 | 能力 |
|---------|------|

## 已知限制

- ⛔ 不支持 KubeJS 接口
- ⛔ 客户端不能在未安装本模组的服务器上统计
- ⛔ 完全免疫（最终伤害 ≤ 0）的事件不计入统计
- ⚠️ 大量历史数据（数万条）的查询运行在主线程，可能影响 TPS
